Bibliography

The reference books behind this book.

This book is a runnable, opinionated reference that points at a small set of excellent books rather than displacing them. Every citation in the chapters is a pointer, something like "see Williams ch. 4 for the full pattern," not a substitute for reading the source. These are books we recommend, not books we wrote; nothing here copies them. If a title is useful to you, please go read it in full.

Citation discipline

Every citation in this book is a pointer, something like "see Williams ch. 4 for the full pattern," not a displacing summary. The books exist; if this book replaced reading them, it would do the authors and the reader a disservice.
