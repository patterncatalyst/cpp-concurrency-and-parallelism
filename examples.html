Running every demo

Clone the repo and invoke each demo.sh from its directory. The scripts assume Docker and a handful of host tools (hey, jq, curl). 

git clone https://github.com/{{ site.github_username }}/{{ site.github_repo }}.git
cd {{ site.github_repo }}/examples/<chapter-slug>
./demo.sh
