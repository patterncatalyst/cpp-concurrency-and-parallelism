# concurrency/24-concurrent-rest Conan recipe (Conan 2.x).
#
# One dependency: Boost, for Boost.Asio + Boost.Beast (async sockets and
# the HTTP parser/serializer on top of them). Both are header-only; the
# only compiled piece either pulls in is Boost.System (for error_code),
# so this recipe disables every other Boost library via without_<lib>
# before the first build, rather than letting Conan build all of Boost
# from source. Verified with `conan graph info` before committing this
# list: with these options the dependency graph resolves to boost + its
# b2 build tool only -- no bzip2/zlib/libiconv/libbacktrace pulled in
# transitively (those come from iostreams/locale/stacktrace, all disabled
# below). shared=False (static libs) means the runtime image needs no
# Boost .so files staged into it at all -- see Containerfile.
#
# without_context=True / without_coroutine=True / without_fiber=True: the
# server and client both use C++20 compiler coroutines
# (boost::asio::awaitable + co_spawn), which run on native compiler
# support, not Boost.Context's stackful-fiber machinery. Boost.Context is
# only needed for boost::asio::spawn()-style stackful coroutines, which
# this demo doesn't use.
#
# without_thread=True: both binaries use std::thread/std::jthread, not
# boost::thread.
